# CP1 Acceptance

CP1 is complete when all are independently verified:

1. Product promise and exclusions are explicit.
2. Golden journey is frozen: 2–3 inputs → extraction → analysis → useful preview → one-time CA$14.99 unlock → full grounded report.
3. Initial categories are frozen.
4. Finding taxonomy and `not stated` trust rule are explicit.
5. Canonical quote and finding/report contracts are documented.
6. Model identities are replaceable configuration rather than product logic.
7. Evaluation requirements include false-positive/no-problem cases.
8. A mobile-first application scaffold demonstrates the intended journey using deterministic fixture data without requiring live providers.
9. QA verifies the exact implementation head against these criteria.
