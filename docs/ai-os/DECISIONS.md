# Decisions

1. `QuoteCheck` is a reversible working name.
2. Web-first and mobile-first; PWA/native packaging follows validated web product.
3. Two-stage AI architecture: inexpensive extraction then stronger contextual reasoning; concrete model identities stay behind configuration/provider interfaces.
4. Run the complete analysis before the unlock; gate presentation, not reasoning quality.
5. Initial categories: General, Automotive, Renovation, Trades/Home Services.
6. Finding classes: explicit fact, difference, not stated, potential risk, inference.
7. Absence of a term is not proof that a charge exists.
8. Domain packs supply context, not exhaustive universal checklists.
9. The system must be able to conclude that no material concern is apparent.
10. Procurement, CRM, marketplaces, quote solicitation, project management and subscription complexity are excluded before the commercial milestone.
11. Material `inference` findings require proposition-level structured grounding, not merely a typed provenance node or lexical/topic overlap. The report contract must identify the inferred subject/canonical target and an interpretation class tied to exact canonical evidence. Deterministic QA verifies target/evidence correspondence and provenance-compatible interpretation; arbitrary qualitative judgments are not considered grounded solely because related canonical evidence exists.
