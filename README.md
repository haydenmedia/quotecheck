# QuoteCheck

Mobile-first quote comparison and second-opinion product.

## Commercial milestone
A stranger can upload 2–3 real quotes, receive a useful free preview, pay a one-time CA$14.99 unlock, and receive a polished grounded report without fabricated findings.

## Product boundaries
Initial categories: General, Automotive, Renovation, Trades/Home Services. QuoteCheck is a gut check/second opinion, not a professional verdict. Procurement suites, vendor CRM, marketplaces, quote solicitation, project management, and subscription complexity are out of scope before the commercial milestone.

Canonical autonomous project state lives under `docs/ai-os/` and GitHub issues/PRs provide execution evidence.
